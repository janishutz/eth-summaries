\subsection{Introduction}
This course uses the xv6 operating system, developed at MIT, for teaching how operating systems work.
This is a cleaned up, simplified version of UNIX v6. Since it is a very simple, yet (basic) feature-complete operating system,
reading its source code is much more straight forward than reading say Linux's source code, which at the time of writing is approximately 40 million lines of code.
